# DinoViet Mod CDN

Bộ pak khủng long mod cho The Isle Evrima (client build 24664737), phát qua GitHub Releases để
[DinoViet Overlay](https://www.dinoviet.com/guide) tự tải vào `TheIsle/Content/Paks/~mods`.

| Release | Nội dung |
| --- | --- |
| [v1.9.2](https://github.com/thuonghoang9x/dinoviet-cdn/releases/tag/v1.9.2) | Các file mới hoặc đã đổi (TekPara, Tapejara, Shant, Theri, roster, spawn zones, skins). Overlay tải từ đây trước. |
| [v1.0](https://github.com/thuonghoang9x/dinoviet-cdn/releases/tag/v1.0) | Các file không đổi từ bản trước (GigaSpino, Anky, Puerta, Quetz, TekRex, TekTrike). |

Overlay kiểm kích thước và SHA-256 của từng file theo manifest đóng gói sẵn trong overlay, nên
file trên CDN phải khớp từng byte.

## Ghi công

Các loài khủng long mod (Spinosaurus, Giganotosaurus, Ankylosaurus, Puertasaurus,
Therizinosaurus, Shantungosaurus, Quetzalcoatlus, TekRex, TekTrike, Tapejara, TekPara) và các
pak đi kèm do đội [IsleVN](https://isle.vn) làm và chia sẻ miễn phí cho cộng đồng.
DinoViet chỉ phân phối lại để người chơi server DinoViet cài được. Toàn bộ công sức làm mod
thuộc về IsleVN.

# DinoViet Mod CDN (English)

Modded dinosaur paks for The Isle Evrima (client build 24664737), served from GitHub Releases so
[DinoViet Overlay](https://www.dinoviet.com/guide) can install them into `TheIsle/Content/Paks/~mods`.

## Credits

The modded species (Spinosaurus, Giganotosaurus, Ankylosaurus, Puertasaurus, Therizinosaurus,
Shantungosaurus, Quetzalcoatlus, TekRex, TekTrike, Tapejara, TekPara) and their paks were made by
the [IsleVN](https://isle.vn) team, who share them with the community for free. DinoViet only
redistributes them so players can join the DinoViet server. All credit for the mods goes to IsleVN.
